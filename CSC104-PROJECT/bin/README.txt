PASSENGER VAN RENTAL SYSTEM (CSC 104)

HOW TO RUN
1. Put all .java files in one folder.
2. Compile:  javac *.java
3. Run:      java Main
(Or open the folder in NetBeans / IntelliJ / Eclipse / VS Code and run Main.java)

FILES CREATED BY THE PROGRAM
vans.txt, customers.txt, rentals.txt  -> saved data (loaded again on next run)
notifications_log.txt                 -> record of every email receipt and SMS sent

NOTE: Email and SMS are simulated (printed on screen + saved in the log).
